# 🕹️ Breakout Game

**Breakout Game** is a classic brick-breaking arcade game, recreated in **C#** using Visual Studio.  
Your goal is to control the paddle, keep the ball in play, and destroy all the blocks to advance.  

This project was built as a learning exercise in C#, focusing on game mechanics, collision detection, and basic game loop logic.

## 🎮 How to Run
1. Open the solution file `Breakout Game.sln` in **Visual Studio**.
2. Build and run the project to start playing.

## ⚙️ Features
- Classic **Breakout** gameplay mechanics.
- Paddle, ball, and destructible blocks.
- Simple and lightweight C# codebase.
